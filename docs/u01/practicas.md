# Prácticas

## P1. Preparar el entorno
Instala Python, comprueba `python --version`, crea un entorno virtual y ejecuta `hola.py`.

## P2. Ejercicios progresivos de Python
1. Pide dos números y muestra suma, resta, producto, división y resto.
2. Convierte grados Celsius a Fahrenheit con `float`.
3. Declara una constante `IVA = 0.21` y calcula el precio final de un producto.
4. Lee un número con `int(input())` controlando `ValueError`.
5. Guarda tres nombres en una lista y muéstralos con f-strings.

## P3. Proyecto con pruebas
Crea un archivo con una función `es_par(n)` y escribe al menos tres pruebas con `pytest`, incluido el caso `0`.

## P4. Git
Sube las prácticas a un repositorio con commits pequeños y mensajes claros. No incluyas claves ni tokens.
