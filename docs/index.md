# Python

Apuntes personales para aprender **Python**, organizados con la misma estructura que la unidad 1 de Programación: del concepto de programa hasta ejecutar y comprobar código.

!!! info "Cómo está organizado"
    Cada apartado responde a una pregunta: *qué es un programa*, *cómo se escribe en Python*, *qué datos maneja*, *cómo se comprueba* y *cómo se prepara el entorno*.

| Apartado | Contenido |
|---|---|
| [U1. Primer programa en Python](u01/index.md) | Estructura, variables, operadores, tipos, pruebas |
| [Mapa de unidades](unidades.md) | U1 a U9: teoría y ejercicios, con los ejercicios de cada unidad debajo de su teoría |
| [Entorno](u01/05-entorno.md) | Instalación, entornos virtuales y `pip` |
| [Prácticas](u01/practicas.md) | Guía de prácticas de la unidad |

!!! note "Qué es Python"
    Python es un lenguaje **interpretado, de tipado dinámico y sintaxis legible**. La indentación forma parte de la sintaxis: marca los bloques en lugar de las llaves.
